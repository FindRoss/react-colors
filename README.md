# React Colors

React Colors — a color palette manager built with React, Redux Toolkit, and TypeScript. Create palettes, add and randomize colors, and copy hex codes to your clipboard, all persisted through a typed Redux store.

## Tech stack

- React
- TypeScript
- Redux Toolkit
- React Router
- Material UI (MUI)

## Getting started

```bash
npm install
npm start
```

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### Other scripts

```bash
npm run build   # production build
npm test        # run tests
```
